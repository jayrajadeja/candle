## Task 1 — `tick` package: the byte contract (read side) + golden guards

**Files:** `tick/tick.go`, `tick/tick_test.go`

- `type Side uint8` with `Buy=0`, `Sell=1`; `String()` → `"buy"`/`"sell"`.
- `type Tick struct { TS, Price int64; Qty uint64; Side Side }`.
- `const RecordSize = 25`, `const HeaderSize = 8`.
- Sentinels: `ErrBadSize`, `ErrBadMagic`, `ErrBadVersion`.
- `func Decode(buf []byte) (Tick, error)` — `ErrBadSize` unless `len(buf)==25`;
  little-endian `{TS[0:8], Price[8:16], Qty[16:24], Side[24]}`.
- `func ValidateHeader(buf []byte) error` — `ErrBadSize` if `len<8`; check first 6
  bytes == `"TCKLOG"` (`ErrBadMagic`), `uint16 LE [6:8]` == `1` (`ErrBadVersion`).

**Tests (RED first):**
- Golden hex → `Decode`: `01000000000000006400000000000000050000000000000000`
  decodes to `{TS:1,Price:100,Qty:5,Buy}`; `…01` tail → `{…,Sell}`. (Same golden
  bytes verified across lob/tickstore — the cross-repo drift guard.)
- `Decode` wrong length → `ErrBadSize`.
- `ValidateHeader`: good `"TCKLOG"`+`\x01\x00` → nil; wrong magic → `ErrBadMagic`;
  version 2 → `ErrBadVersion`; short → `ErrBadSize`.
- `Side.String()`.

**Gate:** `go test ./tick/`.

## Task 2 — `candle` package: aggregation core (pure)

**Files:** `candle/candle.go`, `candle/candle_test.go`

- `type Candle struct { Start int64; Open, High, Low, Close int64; Volume uint64; VWAP int64; Trades int; BuyVol, SellVol uint64 }`.
- `var ErrBadWidth = errors.New("candle: width must be positive")`.
- `func Aggregate(ticks []tick.Tick, width int64) ([]Candle, error)`:
  - `width <= 0` → `nil, ErrBadWidth`.
  - Empty input → `[]Candle{}, nil` (non-nil, len 0).
  - Single pass; bucket index `b = t.TS / width`. Maintain the open candle; when `b`
    advances (strictly greater — input is non-decreasing), append the finished candle
    and start a new one. Append the last open candle at end.
  - Per bucket: `Start = b*width`; `Open` = first price; `Close` = last price;
    `High=max`, `Low=min`; `Volume += Qty`; `BuyVol`/`SellVol += Qty` by `Side`;
    `Trades++`; numerator `num += Price*Qty` (int64); on flush `VWAP = num/Volume`
    when `Volume>0` else `0`.

**Tests (RED first):**
- empty → `len 0`, non-nil, no error.
- `width<=0` → `ErrBadWidth` (0 and negative).
- single trade → one candle, `Open==High==Low==Close==price`, `Trades==1`,
  `Volume==qty`, `VWAP==price`, correct Buy/Sell vol.
- multi-trade one bucket (width 100, TS 0/10/20): OHLC = first/max/min/last; Volume
  and VWAP = Σ(price·qty)/Σqty; Trades==3.
- bucket boundary: TS `99` and `100` with width `100` → two candles; `Start` 0 and 100.
- sparse: TS `0` then `500` width `100` → **two** candles at Start 0 and 500 (no
  empty buckets 100..400 emitted).
- buy/sell split: mixed sides → BuyVol/SellVol partition Volume exactly.
- VWAP integer: pick prices/qtys with non-integer true mean; assert floored int.

**Gate:** `go test ./candle/`.

## Task 3 — `cmd/candle`: CLI shell + render + e2e

**Files:** `cmd/candle/main.go`, `cmd/candle/main_test.go`

- Flags: `--width int` (required; `<=0` → usage error, exit 2), `--csv` bool,
  `--log` bool. Optional positional file arg; no arg → stdin.
- Reader: open file or `os.Stdin`; if `--log`, read+`ValidateHeader` the first 8
  bytes. Then loop: read exactly 25 bytes (`io.ReadFull`); `io.EOF` at a clean
  boundary → done; `io.ErrUnexpectedEOF` → `truncated stream` error; `tick.Decode`
  each; collect `[]tick.Tick`.
- `candle.Aggregate(ticks, width)`; render to stdout:
  - default: aligned table, header `start open high low close volume vwap trades buyVol sellVol`.
  - `--csv`: `start,open,high,low,close,volume,vwap,trades,buy_vol,sell_vol` + rows.
- Extract a testable `run(args []string, stdin io.Reader, stdout, stderr io.Writer) int`
  so `main` is a one-line wrapper (`os.Exit(run(...))`) — the reviewer's lesson from
  lob's emit wiring: make the IO seam unit-testable from the start.

**Tests (RED first):**
- `run` with a bare in-memory record stream (2 records) + `--csv` → exact CSV golden
  (header + 2 rows), exit 0.
- table render golden (aligned columns).
- `--log`: prepend `"TCKLOG"`+`\x01\x00`; run with `--log` → same candles; without
  `--log` on headered input → decode garbage/`truncated` (assert non-zero) —
  actually assert `--log` required for headered input by checking the good path.
- missing/`<=0` `--width` → exit 2.
- truncated tail (24 stray bytes) → exit 1, `truncated stream` on stderr.
- bad magic with `--log` → exit 1.

**e2e (build real binaries, in test or a scripted check):**
- `lob-replay --emit --seed 99 --orders 200 | candle --width 20`: parse the table;
  Σ Trades == lob's emitted trade count (from lob's stderr summary); Σ Volume ==
  Σ Volume from `tickstore dump` of the same stream. Determinism: run twice, byte-
  identical CSV.

**Gate:** `go build ./... && go vet ./... && go test ./...`.
