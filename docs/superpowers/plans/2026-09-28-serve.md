# candle serve — implementation plan (TDD)

Spec: `docs/superpowers/specs/2026-09-28-serve-design.md`. Branch `feature/serve`.
Each task: red -> green -> refactor; keep the full gate green
(`go build ./... && go vet ./... && go test ./...`).

## Task 1 — Extract `candle/feed` (pure refactor)

- New `feed.ReadTicks(r io.Reader, logMode bool) ([]tick.Tick, error)` holding the
  exact framing currently in `cmd/candle/main.go` (header strip/validate,
  truncated-record error, clean EOF).
- `cmd/candle` calls `feed.ReadTicks`; delete the local copy.
- Green = existing cmd golden/table/CSV tests pass unchanged. Add a focused
  `feed` test (header, EOF, truncated). Commit.

## Task 2 — `candle.Source` + `logsource.LogSource` (red -> green)

- Add `Source` interface (`Candles(symbol string, width, from, to int64)
  ([]Candle, error)`) in the candle package.
- Write `logsource` parity test first (red): `LogSource.Candles` == manual
  `Aggregate(feed.ReadTicks filtered to [from,to], width)` over a seeded `.log`;
  missing log => empty; window filter correct; `width<=0` => `ErrBadWidth`.
- Implement `LogSource{dir}`: open `dir/SYMBOL.log`, frame, TS filter, Aggregate.
  Missing file => empty, nil. Green. Commit.

## Task 3 — `candle/server` handler (red -> green)

- httptest table tests first (red): `/healthz`; `/v1/candles` happy path;
  missing/blank symbol -> 400; missing/`<=0`/non-int width -> 400; bad from/to ->
  400; `from>to` -> 200 empty; missing symbol -> 200 empty; unknown path -> 404;
  non-GET -> 405; empty candles encode as `[]`.
- Implement transport-only `Handler(src candle.Source)`: ServeMux, param parse
  (`from` MinInt64 / `to` MaxInt64 defaults), JSON DTOs (non-nil slice), error
  JSON. Green. Commit.

## Task 4 — `candle serve` subcommand

- Dispatch `serve` when `args[0] == "serve"`; otherwise preserve current behavior.
- `runServe(dir, addr, ctx, ready)` mirroring tickstore: `net.Listen`,
  `http.Server.Serve`, `signal.NotifyContext`, graceful `Shutdown` (5s), returns
  nil on clean shutdown / error on bind failure; `ready chan<- string` for tests.
- Add `serve_test.go` ephemeral-port smoke test. Update `usage`/help. Commit.
